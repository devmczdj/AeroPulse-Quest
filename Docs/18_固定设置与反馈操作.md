# v0.16.0 固定设置导航与交互反馈

设置采用固定三标签：显示 / 交互 / 布局。标签一直可见，仅切换内容，不改变天空或配置；原顶部SKY按钮在设置中不再兼任翻页。页脚“返回主卡”恢复原数据/路线页，“收起HUD”保持天空状态，“恢复默认”先说明范围，可取消。

显示页：天空关闭/开启、小读数隐藏/左/右、召回天空。交互页：手背/快捷/前方入口、25/35/45mm高度、操作帮助、提示音开关（默认关闭）。布局页：柔和/快速/固定、1.4/1.8/2.2m、移到面前和编辑位置。全部为指定值选择，重复选择当前值不轮换；手/视野停靠时距离禁用并说明原因，召回后当前模式同步刷新。

增加中文静态字体、确认闪烁、可选轻提示音、首次引导、操作帮助和追踪恢复指引。指引为无碰撞的被动图层，按入口方式变化；首次尚未进入HUD且无输入时保留引导。设置和布局只保存本次运行，未添加持久空间锚。

编辑位置时普通主卡按钮变淡且不可操作；持握达到阈值才显示停靠区，候选区域突出。松手即放置，工具条明确“退出编辑/撤销放置/复位主卡”。手部停靠框第一次显示就使用当前姿态。

新控件回归、30次原响应检查、独立天空/手背/地图/快捷/跟随/停靠、20次完整流程、场景重载、中文缺字/溢出与实际运行时预览通过。确认/取消/切页、重复选择、隐藏控件、停靠距离保护、首帧目标姿态、反馈恢复均有生产输入路径检查。不能把Editor输入注入和相机截图当作Quest的延迟、画质或舒适度结论。

中文使用Noto Sans CJK SC的OFL子集，改名AeroPulse SC；262字符、约82KB源字体，预烘焙静态SDF，运行时不依赖系统中文字体。版权/许可随Resources打包，原上游URL及SHA记录在Assets/Fonts/SourceInfo.json。
