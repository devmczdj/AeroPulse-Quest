## 安装

开发者模式、USB调试已经按前次流程配置。连接USB、唤醒Quest并允许这台电脑调试后，使用本机Android SDK的adb：

```bash
adb devices -l
adb install -r AeroPulse-GlassLab-v0.14.0.apk
adb shell am force-stop com.three.aeropulsemvp.glass
adb shell monkey -p com.three.aeropulsemvp.glass -c android.intent.category.LAUNCHER 1
adb shell dumpsys package com.three.aeropulsemvp.glass
```

devices必须显示device，安装返回Success，包回读versionName=0.14.0 / versionCode=12。不要卸载后重装以处理普通覆盖更新。USB只用于安装/调试/导出；应用核心是本地模拟场景，没有运行时数据服务。依赖首次下载需要联网；Quest系统首次设置/账户状态另按设备实际要求处理。尚未实测本版Quest完全断网冷启动。

## 默认和操作

默认SOFT FOLLOW、1.8m、手背视觉35mm、小读数隐藏。右食指先离开，再从手背正侧轻触左手HUD片打开；打开后片仍为HIDE，再触碰即可收起。显示片抬高与Palm+14mm触碰代理分开；这是关节距离估计。

SETTINGS→BASIC调跟随/距离/手背高度、RECENTER/RESET。SETTINGS上方LAYOUT可切到布局页，SMALL HUD循环左/右/隐藏，HAND ENTRY循环单手背/快捷/前方备用。快捷提供DATA/SKY/RECALL，非默认。

MAP/DATA看数据或五站示意路线，ADVANCE演示移动，SKY MAP看透明天空区域；DETAIL回面前细看，RECALL召回当前视线前上方。HIDE收起详细窗口；可选小读数独立保留，关闭它需SMALL HUD→HIDDEN。

布局页EDIT CARD/EDIT SKY显示把手与停靠区。捏住GRAB + HOLD超过0.15秒开始移动，真实射线指向停靠区会显示预览，释放提交。主卡可世界/视野/左手停靠，天空只世界/视野。DONE退出、UNDO撤销最近一次、RESET复位。失去拖动手/焦点取消；左手丢失时手部卡暂隐，前方RECALL HUD可找回。普通按钮不拖动。

## 一次验收任务

1. 确认手背片不明显嵌手；连续三次“开→收→重开”，分别看142、5:20、3.20、HIDE和模拟标记。
2. 转头比较SOFT/QUICK/FIXED和召回，指向按钮时面板应暂停跟随，移开并放松后恢复。
3. MAP推进一站，SKY MAP→DETAIL，确认当前点和下一站一致；看开再召回，关闭后能重开。
4. 选小读数左/右/隐藏；开启手部快捷，分别DATA/SKY/RECALL；再复位默认。
5. 编辑主卡，依次试世界、视野、手部停靠；观察预览与松手结果，试UNDO、RESET、DONE。
6. 捏合移出追踪再回来、系统菜单切出返回，均应释放再捏才响应。手部停靠丢左手时用前方召回。
7. 关闭应用后冷启动，确认默认恢复；条件允许时断开网络再启动本地场景，记录实际状态。

每项记录版本、是否完成、误操作/提示次数、左右手姿态、文字清晰度、遮挡和主观感受。不适即结束；不据一次通过给出长期/户外结论。多人任务记录仍待招募，当前用户历史短测不累计为不同受试者。
