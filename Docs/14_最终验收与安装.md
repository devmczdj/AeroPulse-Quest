## 安装

开发者模式、USB调试已经按前次流程配置。连接USB、唤醒Quest并允许这台电脑调试后，使用本机Android SDK的adb：

```bash
adb devices -l
adb install -r AeroPulse-GlassLab-v0.17.1.apk
adb shell am force-stop com.three.aeropulsemvp.glass
adb shell monkey -p com.three.aeropulsemvp.glass -c android.intent.category.LAUNCHER 1
adb shell dumpsys package com.three.aeropulsemvp.glass
```

devices必须显示device，安装返回Success，包回读versionName=0.17.1 / versionCode=16。不要卸载后重装以处理普通覆盖更新。USB只用于安装/调试/导出；应用核心是本地模拟场景，没有运行时数据服务。依赖首次下载需要联网；Quest系统首次设置/账户状态另按设备实际要求处理。尚未实测本版Quest完全断网冷启动。

## 默认和操作

默认SOFT FOLLOW、1.8m、手背视觉35mm、小读数隐藏。右食指先离开，再从手背正侧轻触左手HUD片打开；打开后片仍为HIDE，再触碰即可收起。显示片抬高与Palm+14mm触碰代理分开；这是关节距离估计。

点击“设置”，固定三页签“显示 / 交互 / 布局”。显示页独立控制天空和小读数，交互页选择入口/高度/帮助/提示音，布局页选择跟随/距离和主卡位置。选项直接设定所点值，当前选中有描边和底色；重复点当前距离不会召回固定主卡。

“返回主卡”返回此前数据或路线，“收起HUD”不改变天空。“恢复默认”明确列出入口/小读数/高度/提示音/主卡布局，可取消，天空和路线保持。手/视野停靠时前方距离禁用，先“移到面前”才能调整；当前模式会立即更新。

默认提示音关闭，可在交互页开启。按键有短暂确认闪烁；首次进入及追踪恢复时有被动指引，帮助面板不拦截射线。首次尚未成功打开HUD且无输入时，保留操作提示。设置和布局只在本次运行生效。

“编辑位置”显示把手和编辑工具条；捏住达到阈值后出现停靠区，真实命中候选突出，松手即放置。普通主卡按钮在编辑时变淡且不可操作；“退出编辑 / 撤销放置 / 复位主卡”含义明确。天空自身仍无按钮或窗口停靠。

## 一次验收任务

1. 连续点MAP/DATA、设置和ADVANCE，留意是否仍需多次松开重捏才能响应；正确指向后新捏合应立即动作。
2. HUD关闭/重开、数据/地图与RECENTER时，天空保持原来的开关状态；仅SHOW SKY/HIDE SKY改变天空。
3. 身体平移时天空与SOFT HUD随人移动；普通转头天空有环境方向感，转得较远后缓慢回归。悬停按钮不应让SOFT永久停住。
4. 天空应像透明地理层，自己没有按钮/边框/拖拽把手；模拟路线与HUD前方地图共享位置。
5. 原手背显示高度、HUD/HIDE开关、小读数、快捷和主卡停靠/撤销继续回归；失追踪/失焦后释放再捏合才确认。

每项记录版本、是否完成、误操作/提示次数、左右手姿态、文字清晰度、遮挡和主观感受。不适即结束；不据一次通过给出长期/户外结论。多人任务记录仍待招募，当前用户历史短测不累计为不同受试者。
