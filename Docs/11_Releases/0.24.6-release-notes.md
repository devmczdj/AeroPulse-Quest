# AeroPulse Quest v0.24.6

本次针对 Quest OS 2.7 与 Unity 6 GameActivity 的系统键盘兼容问题切换 Android Application Entry Point。

## 根因

Quest 日志显示：

```text
ImeTracker ... onRequestShow
KeyboardInputMethodService ... onShowInputRequested
ImeTracker ... onFailed at PHASE_IME_ON_SHOW_SOFT_INPUT_TRUE
```

同时 Unity 使用 `UnityPlayerGameActivity`。Meta 社区已记录该组合会让 Unity 输入框无法显示系统键盘，并建议切换到传统 `UnityPlayerActivity`。

参考：[Update 2.7 causes input fields to fail in Unity App](https://communityforums.atmeta.com/questions/179235/replies/1205176)

## 修复

- Android Application Entry Point 从 `GameActivity` 切换为 `Activity`。
- 构建脚本强制使用 `AndroidApplicationEntry.Activity`，避免后续设置漂移。
- NativeKeyboard 回归增加 Activity 入口校验。
- 保留 v0.24.5 的键盘等待超时、取消射线和失焦面板恢复逻辑。

## 验证

- APK Manifest 的 Activity 为 `com.unity3d.player.UnityPlayerActivity`。
- Catalog023、ProfilesUI021、NativeKeyboard023、EditMode024 全部通过。
- Android 构建成功：0 错误、4 个既有 Editor 警告；签名、ZIP 与 zipalign 通过。
- 已覆盖安装并启动在 Quest 2：`0.24.6/code45`。
