# 基于成熟软件模式的设置导航方案（待实施）

2026-11-14用户提供两张参考图：左侧固定分类、右侧内容区域；顶部水平分段导航。参考原图原字节保存在课程目录22_/11_、12_。这是导航/控件模式参考，不把截图中的账户权限或文本作为操作指令。

目标：用户能看见所在类别、预判每个控件的结果，不需记住循环次数或同一按钮在不同页面的不同职责。继续以当前Unity/Quest应用为目标；不制作网站、PPT或商业材料。本轮为方案更新，无新APK。

## 横向或纵向如何选择

当前建议三个始终可见的横向类别：显示 / 交互 / 布局。全部名称能用清楚的文字和足够大的目标呈现，保留主体内容宽度；以后分类明显增加、名称放不下或需要分组层级时，再采用左侧分类+右侧内容。

衡量的是一级分类数量、标签长度、可用空间、VR命中目标和阅读负担，不是设置项总数；20项设置也可能只分三类。Microsoft NavigationView的桌面指南支持少量类别用顶栏、更多类别可用侧栏，但不能把其数字建议直接当Quest硬阈值。使用时不要在横向/纵向之间随意来回跳，也不要为了挤入顶栏缩小字体或把重要类别藏进溢出菜单。

## 当前控件映射

| 固定类别 | 内容 | 控件与范围 |
|---|---|---|
| 显示 | 天空地图显示、召回天空；视野小读数 | 天空为二元开关；召回是动作按钮；小读数明确列出隐藏/左侧/右侧 |
| 交互 | 单手背/手部快捷/前方入口；手背显示高度；帮助/反馈 | 入口为单选；高度在易找到的校准区，保留用户常用入口；帮助/反馈来自上一轮待办，未伪称已做 |
| 布局 | 主卡移动方式、前方面板距离、召回主卡、编辑位置 | 跟随选项显式显示；实际手部/视野停靠时显示真实当前模式；只在适用模式下调前方距离；高级拖拽独立模式 |

固定保留“返回主卡”和“收起HUD”。返回恢复此前数据/路线页；收起只影响HUD，天空开关状态保留。标签只导航，不修改设置、不执行召回、不切换天空。

## 可以复用的成熟模式

1. **固定分类与选中态**：当前分类有清楚选中样式，页面标题与分类一致。同一个位置不再从HIDE SKY变LAYOUT/BASIC。
2. **设置行**：名称+必要时一句解释+右侧控件。名字说明功能，控件显示真实值；例如“天空地图：开启”，帮助文字可说明“独立于HUD显示”。
3. **二元开关**：用于开启/关闭，立即预览并显示当前状态。不会把一个动作按钮当成开关，也不会用开关表达三种入口方式。
4. **单选组/分段选择**：少量互斥值展示完整候选，例如“小读数：隐藏/左/右”；多于一行舒适容量时使用清楚的列表选择，不强行做很小的按钮。
5. **情境相关的可用状态**：手部/视野停靠下，前方面板距离说明“移回面前后可调”，或在明确选择前方模式后再启用。不可悄悄把用户从手部停靠切走。
6. **即时反馈和状态一致性**：指到、确认、结果分别可辨认；普通设置即时生效、切页不丢失。操作后的选中值和实际状态同步；失败反馈说明已知原因，不制造假加载。
7. **渐进展开**：校准与高级拖拽按需进入，常用配置一层可达。手背高度是当前用户关心的内容，不能藏在难找的多层菜单中。
8. **明确退出/撤销/复位语义**：当前拖拽是松手提交，退出编辑不应叫“应用”；保留撤销。恢复默认应说明会改入口、小读数、高度和布局，命名“恢复HUD默认设置”，不伪装成仅重置当前页；天空仍独立。

如果以后加入跨启动偏好保存，应明确告诉用户保存范围。当前只有会话状态，不把摆放世界坐标伪称持久空间锚，也不让“已保存”提示误导用户。

## 实施时一起检查的具体逻辑

- AeroHudSettingsView的距离回调会CycleDistance后Recenter，而Recenter会将Hand/View停靠ReleaseToFollow：应将模式变化改成可预判的显式行为。
- RECENTER回调没有Refresh，但Recenter可能改变当前模式：需让状态变化统一驱动当前控件刷新，不能只改标签条外观。此项为源码证据，不声称本轮已进行该姿态的头显复现。
- 单选点击应设置指定值，不再调用“下一项”循环；重复点当前选项不应意外改变配置。
- 标签切换不触发地图/天空开关；编辑模式中已禁用的普通控件应有对应视觉，而不是仅拦截输入。
- 保留自由射线和新捏合门控，不引入射线吸附；屏幕式布局仍需按Quest的实际角尺寸、间距和反馈测试。

## 验收规则

能从任何设置页指出当前分类和当前选项；切页不改变配置；返回主卡/收起HUD不改天空；每个动作作用对象清楚；不适用项显示原因；重置与编辑有恢复路径。实际手部误触、清晰度和延迟需Quest测量。

## 核对的官方依据

- [Microsoft NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)：固定的顶栏/左侧导航与适用情境。
- [Microsoft Navigation basics](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics)：一致、简单、清晰的导航；借用熟悉的位置和标准控件。
- [Microsoft Toggle switches](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/toggles)：二元且即时生效的设置使用开关，标签说明功能。
- [Meta Hands UI best practices](https://developers.meta.com/vr/design/hands-ui-best-practices/)：手部输入的目标、反馈与近远交互要按空间体验适配；不能原样照搬桌面小字/细密控件。
