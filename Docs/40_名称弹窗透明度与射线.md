# 名称弹窗透明度与射线

版本：v0.24.9（Android code 48），2026-11-20。

## 问题

修改档案名称的弹窗原使用 `AeroUiSprites.SolidPanel` 和 alpha `1.0` 背景。世界空间手部射线位于弹窗后方时会被完全遮挡，用户看不到射线路径和落点。

## 修复

- 使用 `JetStyle/RoundedRect` 九宫格圆角底图。
- 使用 `AeroUiTokens.ToolPanelFill`，透明度与主工具面板一致。
- alpha 为 `0.78`，在保持文字对比度的同时透出手部/控制器射线。
- 同时应用于名称编辑框和未保存档案切换确认框。

NativeKeyboard023 回归会检查：

- 弹窗背景 alpha 位于 `0.60` 到 `0.90` 之间。
- 键盘等待态仍可点击取消。
- 手部射线保持启用。
