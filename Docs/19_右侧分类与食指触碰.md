# v0.17.0 右侧分类、连续滑块与食指触碰

## 使用变化

- 设置分类移动到右侧，采用文字导航与中性选中背景；左侧值选项和动作分组，不再同排混成一类按钮。
- 高度25–45mm（1mm步进）、面前距离0.55–2.20m（1cm步进）用连续滑块，显示实时预览值。近处食指按住轨道移动，抬起提交；远处射线捏住轨道拖动，松开提交。切页/失追踪/失焦取消未提交预览。
- 主卡默认0.65m，并随距离按比例缩放，提供可触及的起点且保持视觉大小；手部/视野停靠仍不能暗中用距离控件换模式。
- 近处按钮支持左右食指从正面触碰，无需捏合；同一只手近处触碰优先，远处保留自由射线捏合。按住、滑过其他按钮、恢复追踪保持接触都不会重复确认；同一控件同帧只接受一次操作。
- 手背入口按可见按钮平面触发，移开后再点，不再要求60ms停留。原Palm+14mm仍作为手部布局的参考点，不作为可见按钮的隐形触发面。
- 普通主卡移除品牌眉标/装饰芯片/分割线/多层阴影/描边/反光和装饰性图表；主要界面采用18/22/26/48设计单位字号，缩小原大数字，保留必要的模拟数据说明。场景地图字号按空间场景处理，不把这些单位当网页px。
- 天空仍是独立、无按钮的环境地理层；主卡开关、设置和召回不联动天空。

## 实现和验证

沿用现有XR Hands关节与MetaAim输入路径，参考Meta Poke的连续两帧正面穿越及近处优先规则，没有迁移到另一套SDK。直接触碰保存控件前一帧姿态：面板和手一起平移不形成伪点击，界面移到静止手指下也不算点击。

滑块有单一操作者和固定交互平面，拖动时面板跟随暂停；只在释放提交，尤其避免距离滑块推动自身面板离开指尖。取消不提交值，另一个手不能抢占。

新增AeroTouchChecks覆盖双手点按、快按、正反面、初始重叠、恢复、移动参考系、禁用/隐藏、双手竞争、近远去重、直接/射线滑块的提交/取消/范围与手背可见面。新专项、原完整套件、中文缺字/溢出、20次流程通过frame1205849；重载通过frame2479750。实际4张运行画面已逐张检查。用户明确本轮不做Quest验证，实机触感/画质/舒适度留最后试用。
