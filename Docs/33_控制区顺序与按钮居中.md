# 控制区顺序与按钮居中

版本：v0.24.2（Android code 41），2026-11-20。

## 本轮调整

组件工具顶部改为以下顺序：

```text
环境 / 手部 / 面前
回到面前 / 保持打开
组件 / 档案
组件或档案内容
完成编辑
```

五个层控制按钮中的图标和文字按组合宽度共同计算中心点，因此“环境、手部、面前、回到面前、保持打开”不再偏左。页签移到五个控制项下方，内容列表与页签保持独立间距。
