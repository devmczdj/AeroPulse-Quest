# v0.20.0 组件列表与稳定朝向

2026-11-16。针对试用中“小窗不能单独关闭、每窗工具过多、环绕后文字倾斜、手背不应球面移动”的反馈，改为按需添加独立组件，并分离位置与视觉朝向。此版尚未进行Quest真人验收。

## 使用方式

- **打开列表：** 齿轮 → 显示 → 组件列表；原“布局 → 编辑布局”也进入同一列表。
- **添加：** 点按列表项放到默认空位，或用射线捏住列表项拖出、松手放置。
- **重新编辑：** 已显示项标为“编辑”，选中现有实例；不会重复生成同类窗口。编辑中也能抓住任意已显示窗口的移动把手切换目标。
- **关闭：** 每个窗口右上角都有×。关闭主面板只隐藏主面板，组件和正在使用的列表不被一起关闭；关闭单个组件不影响其他组件。
- **完成：** 点列表里的“完成”，退出编辑并隐藏列表与操作把手。正常显示的数据窗只保留内容和×，没有右侧工具栏。
- 关闭后可从列表重新添加，复用原实例及会话内布局。若组件离开视野，列表编辑或前方召回可帮助找回；手部组件需要有效左手追踪才能在原锚点编辑。

## 位置与朝向

- **环境／面前：** 环绕保持抓取时视点的球面半径，远近独立调整。窗口视觉朝向与视线方向分开计算，文字在屏幕中保持正向，不再累积球面旋转产生的倾斜。
- **环境固定：** 固定的是空间位置；文字仍正向显示。主面板的固定/跟随设置继续可用，已移除每窗右侧重复工具。
- **手部：** 普通把手改名“平移”，沿抓取时的手背平面移动，法线距离不变；另一把手为“离手”，调整离手背的高度。保留手背平面法线，并用视线的上方向稳定平面内朝向，避免额外扭转。手背本身倾斜时窗口仍贴合该平面，不宣称所有角度都与屏幕完全平行。
- **缩放：** 右下角仍支持等比缩放，捕获期间固定操作平面与支点；取消、丢追踪时不提交预览。
- 编辑所选窗口仍有底部环境／手部／面前三项，窗口外不再挂对象、撤销、复位、速度等整列工具。天空仍保持独立被动环境层。

组件选择与布局仍是本次运行内状态，未增加跨应用重启保存或真实房间空间锚点。实体手感、遮挡、文本大小与性能需在Quest上复测。

## 问题与验证

受控的同一动作中，v0.19主面板斜向环绕后的投影文字斜率为4.756262°；v0.20为0°。手部移动的法线漂移从约33.1mm降至浮点误差范围。这里是生产代码的Editor注入复现，不是对截图或实机全部姿态的统计。

11项相关检查通过，覆盖实际射线拖出/点击添加、食指添加、主卡独立关闭、各组件X、关闭后复用、路线联动、三种定位的水平投影、倾斜手背平移、缩放支点、丢追踪取消，以及原手势/设置/天空/快捷/响应/20次旅程。另采样验证隐藏的会话计时持续递增。

旧018/019布局检查入口已转到新组件契约，历史原测试保留在旧版本标签；不继续用“主卡/合并小窗侧栏”或“手部固定球面半径”的旧断言约束新交互。
