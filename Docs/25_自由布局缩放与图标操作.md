# v0.18.0 自由布局、等比缩放与图标操作

更新：2026-11-16。此版落实前两轮已确认的布局和IconMCP方案，并修复交互复核中的五项P2。下列结果来自Unity生产路径和编辑器回归；尚未将v0.18.0安装到Quest做真人验收。

## 进入与操作

1. 打开HUD，点击齿轮进入设置；左栏点阵图标为布局页，右侧点阵按钮进入布局编辑。
2. 编辑栏上排：窗口图标选主卡，小窗图标选小型读数。读数隐藏时小窗选择禁用；先在显示页把读数设为左或右，再编辑。对象名称用于确认正在调整哪一块。
3. **顶部点阵把手移动**：射线指向，捏住片刻后移动，松手放置。起抓保留偏移，不吸到射线中心；短按不会移动。
4. **右下双向对角箭头缩放**：捏住后向外拉大、向内缩小，左上角作为支点，宽高比保持。显示百分比，松手确认；当前工程限值80%–150%，需后续Quest试戴校准。
5. 底排前三个图标选择环境（立方体）、手部（手掌）、面前（头显轮廓）。拖放后保留所选类别和自定义偏移。
6. 环境模式下，右上图钉开=固定于场景；图钉关=延迟跟随。固定后仍可主动拖动。编辑栏的单箭头/快进图标切换柔和/快速，图钉和召回不会清掉速度偏好。
7. 回弯箭头撤销，环形箭头复位当前HUD，勾号完成编辑。常规主卡划线眼睛用于收起；它不是完成编辑按钮。

## 放置与记忆

| 状态 | 行为 |
|---|---|
| 环境固定 | 留在世界位置，不因转头或走动自动移动 |
| 环境跟随 | 保留用户选定的偏移，转头超出死区后延迟平滑跟上；不会强制回正中央 |
| 手部 | 保存左手参考面的相对位置，手移动后偏移保留 |
| 面前 | 保存相机相对位置，随视野立即移动 |

主卡数据/地图/设置共用同一位置；小型读数使用独立的位置、大小和撤销状态。收起重开、内容切换不清掉主卡偏移。距离设置与用户大小倍率分开，改距离保留倍率；附着手部/面前时距离控制仍禁用，召回后可调。

位置与大小目前只记在本次运行中。未增加跨应用重启保存或真实房间空间锚点。天空仍是独立被动环境层；手背入口和前方备用召回入口不随面板搬走。

## 恢复与边界

- 手部失追踪，或者面板摆到视野外，会提供前方召回入口。即使还在布局编辑，也可通过它退出并找回面板。
- 抓取、缩放和滑块同一时刻只由一只手操作；失追踪/失焦取消未完成的预览。
- 操作滑块时暂停附着面板的位置更新，避免移动面板造成改值或提前提交。
- 编辑模式的射线只命中编辑控件和恢复入口，其他面板不会挡住所选小读数的撤销/完成按钮；自由射线方向不被改写。
- 撤销恢复完整布局状态；外部距离/模式调整会使旧主卡撤销失效，避免恢复旧比例。

## 本轮五项修复

| 原问题 | 实现与验证 |
|---|---|
| 手指先接近再停住，UI移近仍点击 | 同时检查累计前进与穿越帧的真实指尖前进；回归包含静止样本和每步0.05mm慢速样本 |
| 手部停靠滑块改值/提前提交 | 捕获期间稳定面板，统一沿捕获平面操作；失追踪取消 |
| 15cm处抓取导致约20cm跳变 | 保存的抓取距离与偏移使用同一数值；静止抓取保持位置 |
| 改距离后撤销缩小界面 | 完整快照加外部修改后的撤销失效，保持距离/倍率/姿态一致 |
| 手背入口背侧误触 | 越界/背侧失去武装，重新要求有效正面穿越；允许两手相对接触 |

## 图标资源与验证
