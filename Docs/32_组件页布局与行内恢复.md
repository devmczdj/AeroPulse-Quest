# 组件页布局与行内恢复

版本：v0.24.1（Android code 40），2026-11-20。

## 布局结构

工具面板按任务顺序分成四个稳定区域：

1. 页签：“组件 / 档案”。
2. 层控制：环境、手部、面前，以及回到面前、保持打开。
3. 内容区：组件列表或档案列表。
4. 页脚：只保留“完成编辑”。

这些区域的矩形范围互不相交。档案列表、保存操作和分页也在独立内容区内，不再伸入页签、层控制或页脚。

组件行采用固定阅读顺序：

```text
[图标] 组件名称        [添加/编辑]  [×关闭]  [↻召回]
```

“添加/编辑”位于恢复按钮左侧；关闭只隐藏对应组件，召回会把该组件重新显示在当前视角前方。按钮文字保留，避免纯图标在首次使用时难以理解。

面板宽度由 480 增至 560，高度由 760 收敛到 700；阅读密度保持稳定，同时减少无效留白。
