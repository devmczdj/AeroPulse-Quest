# 侧边边界对齐

版本：v0.24.4（Android code 43），2026-11-20。

## 布局规则

组件工具使用统一的460单位内容宽度：

- “环境 / 手部 / 面前”三按钮合计铺满左右边界。
- “回到面前 / 保持打开”两按钮合计铺满左右边界。
- “组件 / 档案”页签合计铺满左右边界。
- 组件行、档案列表和“完成编辑”保持同宽。

因此所有主要内容的左、右边缘分别落在相同基准线上。面板仍保留左右40单位的内部留白，避免文字或按钮贴近外框。

## 检查

- 层控制背景、内容页、页签组合、组件行和完成按钮的左右坐标误差均不超过1单位。
- 第一排与第二排控制按钮的外缘分别与层控制背景对齐。
- 关闭按钮仍位于组件行最右侧，只显示叉号。
- 组件行操作之间无重叠。
