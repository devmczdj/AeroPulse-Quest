# 系统键盘恢复路径

版本：v0.24.5（Android code 44），2026-11-20。

## 问题

用户点击档案名称时，系统键盘没有稳定显示，但应用已经把 `KeyboardInputActive` 设为真。系统键盘切换焦点后，应用又暂停了工具面板，射线同时因失焦被关闭，最终无法点击取消。

## 修复

键盘输入拆成两个阶段：

1. **Opening**：已请求系统键盘，但尚未确认可见。此阶段面板保持运行，射线可见，只允许点击“取消”。
2. **Active**：检测到键盘状态为 `Visible` 或 `TouchScreenKeyboard.visible` 后，再正式接管键盘输入。

如果在3秒内没有检测到可见键盘，应用会自动结束本次键盘会话、恢复全部输入，并显示可重试或使用预设名称的提示。

系统键盘导致 Unity 失焦时，普通布局操作暂停，但键盘取消面板不再被 `Layout.SetPaused(true)` 隐藏。手部和控制器射线在键盘模式下仍可指向取消按钮；其他按钮、把手和背景继续隔离。
