# 课程商业表达与问答

目标用户是需要短时查看训练指标与路线的耐力运动爱好者；是否愿意佩戴/付费仍待访谈。沿用统一定位：Vanguard是运动记录工具，我们是平视仪表+体征直达（设计方向）。Meta官方介绍其相机、运动App整合和音频：https://about.fb.com/news/2025/09/oakley-meta-vanguard-performance-ai-glasses-sports/ （2026-11-14查阅）。本项目不提供市场占有率/销量预测。

课堂成本和定价算例（全部人为情境假设，非询价/团队已批准预算）：售价1999元，单件变动成本1200元，渠道/售后预留199元，单位贡献1999-1200-199=600元。若固定投入30万元，则算例平衡点300000/600=500件。未计入完整税务、融资、退货、产量爬坡和良率模型，不代表真实制造成本或利润承诺。下一步分别取得显示/结构/电子/装配报价，再更新模型；不从渲染图倒推已实现量产成本。

模拟众筹页明确“不收款、不承诺交付”，不构成真实上线销售。产品描述聚焦可演示信息交互，外观用团队模型软件视图；真实传感器、GPS、续航、光学、重量均保留目标/待验证标签。

- 为什么用Quest？快速验证入口、信息层次和空间布局，不能替代眼镜的重量、光学、功耗或户外验证。
- 这些心率和位置是真的吗？不是，数值固定、位置由ADVANCE推进，并持续标记模拟。
- 天空地图和地面是否对准？没有真实配准，是有地形轮廓和水系的示意区域。
- 手丢失怎么办？释放确认门控；手部停靠界面暂隐，前方召回可恢复，追踪恢复保持捏合不会自动点击。
- 是否支持毛玻璃透视？目前是静态全景下的玻璃近似，未实现实时Passthrough背景模糊。
- 是否已经证明安全舒适？只有当前用户早期短时反馈；新功能和最终画质需集中验收，长期/户外和多人验证尚待做。
- 何时量产？目前为课程概念与交互原型，无对外发货承诺。先完成最终Quest验收，再做实际硬件链路及多人研究。
