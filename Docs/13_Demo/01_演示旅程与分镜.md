# AeroPulse 演示旅程（0.13.0）

室内Quest原型，一段完整演示控制在60–90秒。使用手追，数据与地理层全为模拟。先唤醒并确认手追，再进入应用；不要以跑动拍摄代替室内交互演示。

| 时间 | 演示动作 | 观众应看到 | 讲述 |
|---|---|---|---|
| 0–8秒 | 展示团队眼镜视图 | 黑色盾片与双镜腿、模型软件界面 | 这是团队模型视图，下面用Quest验证信息交互 |
| 8–18秒 | 抬左手、右食指离开后轻触手背 | HUD打开，142/5:20/3.20及SIMULATED DATA | 需要时调出三项运动信息 |
| 18–30秒 | MAP、ADVANCE一次 | 下一站与当前点同步变化 | 路线是示意数据，按钮演示位置推进 |
| 30–43秒 | SKY MAP、DETAIL | 透明天空区域与面前细看切换 | 总览放到天空，需要细看再回前方 |
| 43–55秒 | SETTINGS→LAYOUT；小HUD左/右/隐藏 | 小读数与主卡分开锚定 | 选择适合当前任务的位置 |
| 55–70秒 | EDIT CARD；捏把手>0.15秒，移到WORLD/VIEW框，释放，DONE | 真射线落点预览与释放停靠 | 拖动是单独的明确操作，还可撤销或复位 |
| 70–80秒 | 手背再次轻触或HIDE | 面板收起，环境可见 | 看完收起，保留重新打开入口 |
| 80–90秒 | 展示能力映射 | 软件/模拟/硬件目标三个层次 | 真实传感器、光学和户外性能是下一阶段 |

该分镜替代旧草案用于本轮实演，旧原文不改。自动放大、镜腿双击/调光、速度检测、震动、自动退出不是当前实现，不加入演示。完整设备验收待用户最后统一进行。
