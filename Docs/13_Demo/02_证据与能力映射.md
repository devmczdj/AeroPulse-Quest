# 实现、模拟与待验证

| 内容 | 状态与依据 |
|---|---|
| 手背开/关、自由射线、新捏合 | 已实现；早期单用户短时反馈存在，后续版本按自动检查，不延伸为多人验证 |
| 手背显示高度/跟随设置 | 0.9.1已修正与Editor验证，实际遮挡、点击手感由最终试戴确认 |
| 前方/天空地图与小读数 | 0.10–0.11已自动验证/构建/云端回读；固定模拟数值与虚构五站 |
| 拖拽/停靠与手部快捷 | 0.12已实际射线注入验证；无真机手感结论 |
| 团队模型视图 | 用户2026-11-14提供；未接入可交互3D资产，未检验尺寸或重量 |
| 体征/GPS/蓝牙 | 未接入；不可据此诊断身体、导航真实道路 |
| 模型重量≤39.5g、光波导/传感器能力 | 设计目标；Quest原型不提供验证证据 |
| 多人访谈 | 既有任务要求5–8人，当前资料未发现已完成原始记录；不虚构替补 |

早期单用户原话：“左右手都正常，文字清楚”；末轮三项“都正常，无明显不适”；Glass Lab“外观更好，跟随自然，点击正常”。后来出现摩尔纹/HIDE模糊、手背嵌入/入口消失/跟随失效反馈，已驱动资源/高度/状态/设置修正。这些是多轮同一用户反馈，不能累计成多个受试者或成功率。

后续多人任务表：分别完成开/关、地图/天空切换、推进/召回、停靠/撤销；记录任务完成、误触、提示次数、左右手姿态、舒适度、原话与设备版本。记录空缺保持空缺。

设计依据：Microsoft Hand Menu https://learn.microsoft.com/en-us/windows/mixed-reality/design/hand-menu （关注手不可用时备选），Meta hand interaction model https://developers.meta.com/vr/design/hands-choosing-an-interaction-model/ 。应用于本项目是设计选择，不意味着官方认证或统一产品方案已裁决。
