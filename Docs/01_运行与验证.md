# 运行、构建与验证

Unity 6000.6.8f1，Android Build Support（SDK/NDK/OpenJDK），Meta Quest 2，启用开发者模式与USB调试。Packages/manifest.json与packages-lock.json保留实际依赖版本；首次导入需下载依赖。应用本身是本地模拟场景，无GPS/体征服务器。

打开项目后运行Assets/Scenes/SampleScene.unity。手追可在Quest验证；Editor回归为注入输入，不能替代实际接触/遮挡/舒适度。

## 使用

左手手背朝向自己，右食指先移开再轻触HUD片打开。大卡打开后手背仍显示HIDE，再次新触碰收起。大卡按钮沿用手部自由射线和释放后新捏合。MAP/DATA、ADVANCE/RESET、HIDE会保持会话地图位置。

SETTINGS可切SOFT FOLLOW/QUICK FOLLOW/FIXED HERE、1.4/1.8/2.2m、手背显示25/35/45mm，并提供RECENTER/RESET DEFAULTS。重启恢复默认。显示抬高不移动Palm+14mm的触碰代理；实际贴合还需Quest校准。

## CLI构建（main）

在项目根目录，使用已安装并登录的Unity CLI：

```bash
unity open . --editor-version 6000.6.8f1
unity status --until-ready --project-path "$PWD" --format json
unity command eval --caller plugin --skill unity-cli --project-path "$PWD" 'AeroUiBuild.Build();'
```

首次克隆后，先在Unity Build Profiles中激活Android构建目标，再执行构建命令；AeroUiBuild会检查活动目标，其他目标会明确报错。

当前输出为Builds/AeroPulse-GlassLab-v0.11.0.apk；随软件版本更新。main使用可选AEROPULSE_ARCHIVE_DIR导出到外部归档目录；默认仅在工程内输出。需要代理下载Gradle依赖时，在Editor进程中显式设置AEROPULSE_GRADLE_PROXY_PORT，使用本机真实端口，不写入凭据或替其他人固定代理。

历史tag v0.9.1保留当时源码，其Editor归档路径仍为原开发机目录；跨电脑构建优先使用main。发布APK来自该tag对应的原构建，不能把main的编辑器路径整理误记为重新构建了APK。

## Editor回归

使用CLI启用auto tick并进入Play Mode，确认Time.frameCount推进，再依次运行AeroHandBackChecks.Run()、AeroViewOptionsChecks.Run()、AeroGlassChecks.Run()；读取console errors后退出。测试会注入手状态并修改场景实例，使用重新加载的SampleScene。旧光球仅作为Editor回归夹具显式启用。

当前证据见05_与06_；v0.9.1仍待Quest实机确认，不宣称皮肤触碰、遮挡消除、性能或多人体验通过。

天空总览：主卡上方SKY MAP调出，DETAIL回面前细看，RECALL按当前朝向召回，HIDE收起；两态共享演示位置，天空保持在打开时的会话世界位置。图层为自编示意地理，不是实际GPS或地物配准。

布局页：打开SETTINGS后点上方LAYOUT，SMALL HUD循环HIDDEN/LEFT/RIGHT；小读数独立于详细面板，HIDE仅收起详细窗口。HAND ENTRY可选HAND BACK或FRONT BUTTON；后者关闭大卡后显示视野下方OPEN HUD，仍需要手射线/新捏合。默认复位恢复手背和隐藏读数。
