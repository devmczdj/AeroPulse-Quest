# 运行、构建与验证

> 当前源码 v0.22.2（Android code 24）。日常点击主卡 × 仅收起 HUD，不关闭小组件或改写档案。手背操作、档案和分层编辑见[当前操作说明](30_按需工具与分层编辑.md)。

Unity 6000.6.9f1，Android Build Support（SDK/NDK/OpenJDK），Meta Quest 2，启用开发者模式与USB调试。Packages/manifest.json与packages-lock.json保留实际依赖版本；首次导入需下载依赖。应用本身是本地模拟场景，无GPS/体征服务器。

打开项目后运行Assets/Scenes/SampleScene.unity。手追可在Quest验证；Editor回归为注入输入，不能替代实际接触/遮挡/舒适度。

## 使用

左手手背朝向自己，右食指先移开再轻触HUD片打开。大卡打开后手背仍显示HIDE，再次新触碰收起。大卡按钮沿用手部自由射线和释放后新捏合。MAP/DATA、ADVANCE/RESET、HIDE会保持会话地图位置。

打开 HUD，进入「设置 → 布局 → 编辑布局」。进入后会打开工具面板，可通过右手手背再次调出。点「完成编辑」后，移动和缩放把手、组件关闭按钮及右手工具一起收起。要让布局在重启后恢复，在编辑时将它存为档案。

## CLI构建（main）

在项目根目录，使用已安装并登录的Unity CLI：

```bash
unity open . --editor-version 6000.6.9f1
unity status --until-ready --project-path "$PWD" --format json
unity command eval --caller plugin --skill unity-cli --project-path "$PWD" 'AeroUiBuild.Build();'
```

首次克隆后，先在Unity Build Profiles中激活Android构建目标，再执行构建命令；AeroUiBuild会检查活动目标，其他目标会明确报错。

v0.22.2 的构建输出路径为 `Builds/AeroPulse-GlassLab-v0.22.2.apk`。main使用可选AEROPULSE_ARCHIVE_DIR导出到外部归档目录；默认仅在工程内输出。需要代理下载Gradle依赖时，在Editor进程中显式设置AEROPULSE_GRADLE_PROXY_PORT，使用本机真实端口，不写入凭据或替其他人固定代理。

历史tag v0.9.1保留当时源码，其Editor归档路径仍为原开发机目录；跨电脑构建优先使用main。发布APK来自该tag对应的原构建，不能把main的编辑器路径整理误记为重新构建了APK。

## Editor回归

使用CLI启用auto tick并进入Play Mode，确认Time.frameCount推进，再依次运行AeroHandBackChecks.Run()、AeroViewOptionsChecks.Run()、AeroGlassChecks.Run()；读取console errors后退出。测试会注入手状态并修改场景实例，使用重新加载的SampleScene。旧光球仅作为Editor回归夹具显式启用。

v0.22.1 专项入口为 `AeroEditMode024Checks.Run()`，覆盖从设置进入与完成编辑、日常模式下的输入、启动恢复与跨模式持续捏合。Quest 佩戴验收步骤见[按需工具与分层编辑](30_按需工具与分层编辑.md)。
