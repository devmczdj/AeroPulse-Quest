# 布局档案与近手抓取

v0.21.0 / Android code 20，2026-11-17。实现说明；最终验证状态见同版发布校验与Editor记录，Quest手感仍需佩戴确认。

## 怎么使用

1. 从设置进入编辑布局，左侧面板顶部可切换“组件 / 档案”。组件仍是心率、配速、距离、下一站、会话计时五项，各自用 × 关闭。
2. 远处继续用射线捏合。近处把拇指和食指张开放到顶部把手附近，出现高亮后捏住移动，松开提交。右下角缩放把手也支持近手捏合。
3. 手部组件的“平移”沿抓取时的手背平面移动，“离手”只调整离手背的高度。环境/面前仍是“环绕 / 远近”，右下角保持等比缩放，倍率80%–150%。
4. “档案 → 保存”保存当前档案；第一次保存和“另存”会打开命名。可选日常/运动/演示名称，或用字母、数字、空格键盘输入；目前不含中文拼音输入法。最多12个档案、名称最多24字，四项一页。
5. 点击另一档案的“启用”可切换。有未保存的修改时，选择“保存并切换 / 放弃并切换 / 取消”。普通修改不会自动覆盖已保存档案。
6. 应用下次启动，在收到有效头部追踪后恢复最近启用档案的已保存状态。未保存改动不跨启动恢复。

## 保存范围

保存主面板与五个组件的显隐、放置方式、相对位置、物理尺寸/倍率、跟随偏好。不保存心率等读数、路线进度、会话经过时间，也不改变独立天空地图。

手部位置相对左手手背，面前位置相对视点，柔和跟随保存用户偏移。环境固定位置在**每次启用或重启时按当前视点重新建立**，不是上一房间的永久空间锚。手部档案在左手未追踪时保持隐藏，找回左手后再显示。

档案文件位于应用自己的 `Application.persistentDataPath/layout-profiles-v1.json`。写盘成功后才更新“已保存/已启用”状态；先写临时文件并替换，保留上一份完整备份。无效数值、未知版本或损坏内容不直接应用，损坏原件保留以供恢复。正常覆盖安装同包名APK保留应用数据；卸载应用会删除应用数据。

## 输入规则

- 靠近不等于拖动；必须在同一把手附近先张开，再新捏合。
- 一次只允许一只手拥有拖动；近手捕获期间，同手射线和两手按钮确认暂停。
- 失追踪、焦点丢失或取消会回到抓取前状态；保持捏合重新进入追踪范围不会自动抓取。
- 命名和切换确认弹窗期间，背景把手、关闭按钮和手背开关不抢输入。
- 初始参数为捏合25mm、释放40mm、近把手40mm，均为待Quest调试的阈值，不能当成传感器精度或可用性实测。

## 实现与证据边界

`AeroNearManipulation`读取实际拇指/食指关节；近/远输入共用`AeroWindowLayout`的参考平面、球面、倍率、提交与取消事务。`AeroLayoutProfiles`负责版本化数据与文件替换；`AeroLayoutProfileView`负责命名、保存和切换确认。

Editor专项检查覆盖近手释放门控/双手冲突/失追踪、布局参考系往返、存储损坏/写盘失败、真实射线操作档案界面。检查通过与渲染预览不代表Quest手指遮挡、实际触碰范围、性能和舒适度已通过。

布局档案借鉴[Lunar Client官方mod profiles说明](https://www.lunarclient.com/news/the-benefits-of-using-lunar-client-as-a-content-creator)，没有移植客户端代码。三维参考系与手部输入规则为本项目实现。
