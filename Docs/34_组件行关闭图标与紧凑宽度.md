# 组件行关闭图标与紧凑宽度

版本：v0.24.3（Android code 42），2026-11-20。

## 调整

组件行最终顺序：

```text
[组件图标] 名称     [添加/编辑]  [↻召回]  [×]
```

关闭按钮位于行尾，仅显示叉号并保留 42×42 布局尺寸和更大的碰撞命中区。召回继续显示图标与简短文字，帮助首次使用者理解。

工具面板宽度从560调整为540，内容页宽度从520调整为500。顶部层控制、页签和档案页继续使用同一内容宽度。

## 检查

- 关闭按钮位于召回按钮右侧。
- 关闭按钮不再显示“关闭”文本。
- 关闭按钮宽度不超过44个布局单位。
- 添加/编辑、召回和关闭互不重叠。
- 组件页与档案页均未重新出现内容挤压。
