# 0.12.0 布局编辑与手部快捷

SETTINGS → LAYOUT → EDIT CARD / EDIT SKY进入布局编辑。只捏住GRAB + HOLD把手超过0.15秒才拖动；指向停靠框后看到落点预览，松手提交。主卡支持WORLD、VIEW、HAND；天空仅WORLD、VIEW。DONE退出，UNDO撤销最近一次，RESET恢复默认。非编辑状态不拖动内容。

HAND ENTRY可循环SINGLE手背 / HAND SHORTCUTS / FRONT按钮。快捷模式提供DATA、SKY、RECALL，默认仍手背。手背按钮打开后保持HIDE，可再次轻触收起。手丢失时手部停靠界面与碰撞体隐藏，前方RECALL入口可恢复。

自动检查通过：真实自由射线与新捏合、落点预览/提交、双手不抢占、失追踪/失焦取消、撤销/复位、头部/世界/手部锚定、丢手召回、天空位置会话内重开保持、可选快捷与恢复门控、原HUD/地图/跟随回归。最终一次完整回归frame74041，0错误/警告。SendMessage曾广播给同物体的禁用手追读取器，现测试定向调用运行时同一ProcessInput；手部停靠框实际渲染过大已缩为0.45倍并重验。

预览为Unity运行时相机渲染，注入手部锚点，不含真人手追或头显画质验证。所有体征/路线为模拟；设置/布局只在本次运行保存，非持久空间锚。按用户要求最终再做Quest验收。
