# 系统键盘语言说明

版本：v0.24.8，2026-11-20。

## 为什么没有语言选择

Quest 的“设备 → 虚拟键盘”不是输入法语言管理器。当前 Horizon OS 页面没有单独的“键盘语言”子页面，也没有“添加中文输入法”入口。

设备实测：

```text
system_locales=zh-CN
Oculus Keyboard subtype=英语（美国）
```

“常规 → 本地化 → 语言”可以改变系统界面语言，但不会自动给系统键盘增加中文 subtype。应用拿到的是系统键盘，也无法通过 Unity API 强制加载或选择中文输入法。

## 当前可用方式

1. 使用应用内已有的中文预设名称“日常 / 运动 / 演示”。
2. 使用英文、数字名称。
3. 如果系统键盘中以后出现地球图标，才表示存在多个可用键盘语言，可以切换。
4. 第三方中文输入法需要在Quest助手类工具中侧载并切换输入法，属于系统级非官方方案，当前版本未集成。
5. 需要完全离线、确定可用的中文命名时，下一步应在应用内实现自有拼音候选或中文快捷命名，而不能依赖当前Meta系统键盘。

名称弹窗已改成“语言由系统键盘决定”，不再提示不存在的“地球键切换中文”。
