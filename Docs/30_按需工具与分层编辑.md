# 按需工具、分层编辑与系统键盘

v0.22.1（Android code 23），2026-11-18。

## 操作

- **运动时**，用右食指轻触左手手背开关主 HUD。已启用的心率、配速等组件只显示读数。右手工具、组件 × 和移动、缩放把手都隐藏，手碰到读数也不会移除它。
- **调整布局时**，打开主 HUD，点「设置 → 布局 → 编辑布局」。此时工具面板出现在前方，能追踪到的右手手背显示工具入口。「显示」页的「布局设置」只跳转到布局页。
- 编辑期间，左食指先离开再轻触右手工具，或用左手射线捏合，可收起或调出面板。每次重新打开时，面板回到当前视点前方。
- 默认单次添加：成功添加或从列表拖出并释放后，列表自动收起，选中组件仍可编辑。打开“保持打开”后可连续添加；此偏好在本次运行内保持，不属于布局档案。
- 选中已有组件、切换分类/编辑层、取消拖动不自动收起。保存/另存/改名/启用成功后按“保持打开”决定是否收起；保存失败保留界面。收起列表不等同结束编辑，也不关闭已添加组件。
- 工具打开时选择“环境 / 手部 / 面前”。只显示当前层已启用组件；点组件选中，只有选中项展开移动、远近/离手、缩放和放置控件。新增或重新添加默认进入当前层；已显示组件从列表选择时回到它所属层，不复制实例。
- “环境”包括既有环境固定和柔和跟随状态。手部仍沿手背平面平移和法线调整离手高度；面前沿视点相对区域放置。右下角等比缩放保持原规则。
- “全部预览”收起工具及编辑把手/关闭按钮，显示各层原本启用的组件；重新打开工具后点某层或再次切换预览，即可继续编辑。已关闭的组件不会被预览重新打开。
- 编辑或预览时若右手入口不可用，只临时显示小型“打开工具”备用按钮，可用左手射线恢复；此动作不会召回或移动布局。手部追踪丢失会暂时隐藏依赖该手的组件，并给出恢复提示。
- 点「完成编辑」退出，右手入口、工具面板、组件 × 和编辑把手立即收起。各层恢复显示已启用的组件。要在下次启动恢复这套布局，请先将布局保存为档案。

## 名称输入

点击档案名称调用Quest系统覆盖键盘（当前OpenXR1.19已有支持），不再维护自制字母/数字按键。键盘“完成”只更新名称草稿，仍需点应用中的“保存”；取消或失去键盘焦点不覆盖原名称。键盘占用输入时，背景HUD与手背开关不响应，恢复后要求新的释放/输入。

名称最多24个UTF-16字符位置，长名称在应用字段/列表中省略显示但不截断保存内容。支持字体可显示的字符；控制字符或缺失字形会明确拒绝保存。新增动态Noto CJK回退字体，避免旧322字符子集出现中文方框；系统键盘不可用时保留自动名称和日常/运动/演示预设。Editor一般不会显示Quest的系统键盘。

Meta系统语言/输入法可用性由头显系统决定，本版未声称已通过中文拼音实机测试。

## 状态与实现边界

层过滤只改变Canvas/碰撞体，不改变组件activeSelf或档案显隐；切层不修改布局数据、路线和计时。现有档案schema1及稳定组件ID保持，临时层选择/预览/工具开关不写成组件关闭。

工具面板的可见顺序与射线优先级一致，空白背景阻挡穿透；被盖住的近手/触碰控件不响应，外露区域仍可编辑。复用原射线、HandBackTouchGate、布局事务与本地图标，没有新增XR交互框架。工具背景复用现有实心Pill纹理作九宫格圆角，数据卡片保持原透明度。

系统键盘使用Meta Quest Support的Enable System Keyboard与TouchScreenKeyboard.Default；不引入Meta XR Core/OVRVirtualKeyboard。APK核验应含oculus.software.overlay_keyboard且required=false；构建报告确认完整CJK字体约16.4MB源数据进入包内。完整字体会增加包体，换取稳定的名称字形覆盖。

## v0.22.1 佩戴验收

1. 启用包含心率等组件的档案后结束编辑。收起主 HUD，观察读数仍在，然后分别用手指触碰、射线捏合组件原 × 位置。预期组件留在原位、右手无工具。
2. 用左手手背打开 HUD，先点「显示」页的「布局设置」，再点「编辑布局」。预期第一步只换设置页，第二步才看见右手工具，并能移动或关闭当前层的组件。
3. 点「完成编辑」，观察工具和编辑按钮立即收起。重启应用恢复已存档案，或在日常查看时摘戴头显，预期继续显示读数，编辑仍需从设置进入。

## v0.22.0 历史验证

23个新旧Editor检查入口通过：分层与保存隔离、单次/连续添加/取消、只读预览、右手工具与左手恢复、工具覆盖优先级、近手/射线/触碰、命名草稿与保存、焦点/取消/字形/长名称边界，以及既有地图/设置/连续旅程。新增旧检查前置明确选择“保持打开”或收起遮住目标的工具，不把不可见控件当可点目标。

运行画面来自真实Editor相机，手部/视点和系统键盘返回值由检查注入；原生系统键盘画面、手感、舒适度和Quest性能未冒充实测。
