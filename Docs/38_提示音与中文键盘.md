# 提示音与中文键盘

版本：v0.24.7（Android code 46），2026-11-20。

## 确认提示音

此前 `AeroInteractionFeedback.Build()` 将 `SoundEnabled` 固定为 `false`，所以声音默认消失。当前版本改为：

- 无用户偏好时默认开启。
- 开关写入 `AeroPulse.FeedbackSoundEnabled`，下次启动继续使用上次选择。
- 提示音音量从0.12提高到0.18。
- 设置页的“提示音 开/关”继续使用同一状态。

设备媒体音量检查为15/15，说明音量不是系统静音导致的。

## 中文输入

Quest 当前：

```text
system_locales=zh-CN
default_input_method=com.oculus.vrshell/.../KeyboardInputMethodService
keyboard subtype=英语（美国）
```

系统语言虽然包含简体中文，但键盘当前没有可用的中文 subtype。应用无法通过 Unity API 替用户安装或选择系统输入语言。

操作路径：

1. 打开 Quest 通用菜单。
2. 进入 `Settings > System > Language and Region > Language`。
3. 确认加入“简体中文”。
4. 打开系统键盘，使用地球图标切换语言。

名称弹窗现在直接提示“地球键切换中文”。

Meta 官方说明：

- https://developers.meta.com/horizon/documentation/unreal/unreal-keyboard-overlay/
